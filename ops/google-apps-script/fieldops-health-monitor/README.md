# FieldOps 公開監視の運用手順

この手順は、GoogleスプレッドシートとGoogle Apps ScriptでFieldOps Portalの公開デモを毎日10:00以上18:00未満に10分おきで確認するためのものです。18:00から翌9:59まではFieldOpsへアクセスしません。

この監視は外から公開URLへアクセスして状態を記録する外形監視です。

Render Freeは15分間通信がないと停止するため、10分監視が動く10:00〜18:00の間は通常スリープが抑えられます。ただし、Render側の再起動や停止を保証付きで防ぐ機能ではありません。

Googleパスワード、Renderトークン、Cookie、APIキーは不要です。

作成するGoogleスプレッドシートは共有設定を非公開のままにし、必要な人以外へ共有しないでください。

## 初期設定

1. Googleスプレッドシートを開きます。
2. 画面左上の**空白のスプレッドシート**を押します。
3. ファイル名を**FieldOps 公開監視**に変更します。
4. 右上の**共有**を押します。
5. **一般的なアクセス**が**制限付き**になっていることを確認します。
6. 共有設定は非公開のままにして、必要な人以外を追加しません。
7. 上部メニューの**拡張機能**を押します。
8. **Apps Script**を押します。
9. Apps Script画面で**Code.gs**を開きます。
10. リポジトリの`ops/google-apps-script/fieldops-health-monitor/Code.gs`の内容で、画面内のコードをすべて置き換えます。
11. Apps Script画面で**プロジェクトの設定**を開きます。
12. **「appsscript.json」マニフェスト ファイルをエディタで表示する**をオンにします。
13. 左側のファイル一覧で**appsscript.json**を開きます。
14. リポジトリの`ops/google-apps-script/fieldops-health-monitor/appsscript.json`の内容で、画面内の内容をすべて置き換えます。
15. 上部の**保存**を押します。
16. 関数の選択欄で**setupMonitoring**を選びます。
17. 上部の**実行**を押します。
18. 権限確認画面が出たら、使うGoogleアカウントを選びます。
19. 警告画面が出たら、表示内容を確認して**詳細**を押します。
20. **FieldOps 公開監視（安全ではないページ）に移動**を押します。
21. 権限一覧を確認し、問題なければ**許可**を押します。
22. スプレッドシートへ戻ります。
23. 上部メニューの**FieldOps監視**を押します。
24. **初期設定を作成**を押します。
25. **監視設定**シートを開きます。
26. **公開URL**が`https://fieldops-portfolio.onrender.com`になっていることを確認します。
27. **通知先メール**が自分のメールアドレスになっていることを確認します。
28. 通知先メールが空欄または違う場合は、本人が受け取れるメールアドレスを入力します。
29. 上部メニューの**FieldOps監視**を押します。
30. **今すぐ確認**を押します。
31. **監視履歴**シートを開きます。
32. 最新行の**総合結果（正常／異常）**が**正常**であることを確認します。

## 監視を開始

1. スプレッドシート上部の**FieldOps監視**を押します。
2. **10:00〜18:00の10分監視を開始**を押します。
3. Apps Script画面を開きます。
4. 左側の**トリガー**を押します。
5. 関数名が**runHealthCheck**のトリガーが1件だけあることを確認します。
6. スプレッドシートへ戻ります。
7. **監視設定**シートの**監視状態**が**監視中（10:00〜18:00／10分おき）**になっていることを確認します。
8. 自動監視は10:00以上18:00未満の間だけ、約10分おきに実行されます。Google側の都合で実行時刻が少し前後することがあります。

## 監視を停止

1. スプレッドシート上部の**FieldOps監視**を押します。
2. **監視を停止**を押します。
3. Apps Script画面を開きます。
4. 左側の**トリガー**を押します。
5. 関数名が**runHealthCheck**のトリガーが残っていないことを確認します。
6. スプレッドシートへ戻ります。
7. **監視設定**シートの**監視状態**が**停止中**になっていることを確認します。
8. 停止するときも、GASコード、スプレッドシート、FieldOps本体は削除しません。

## 異常通知テスト

1. **監視設定**シートを開きます。
2. **通知先メール**が本人のメールアドレスであることを確認します。
3. 上部メニューの**FieldOps監視**を押します。
4. **テスト用の異常通知**を押します。
5. **監視履歴**シートを開きます。
6. 最新行の**総合結果（正常／異常）**が**異常**であることを確認します。
7. メールボックスを開きます。
8. 件名が**[FieldOps監視] 公開環境の異常を検知しました**のメールが届いていることを確認します。

## 復旧通知テスト

1. 異常通知テストが終わった同じスプレッドシートを開きます。
2. 上部メニューの**FieldOps監視**を押します。
3. **テスト状態を戻す**を押します。
4. **監視履歴**シートを開きます。
5. 最新行の**総合結果（正常／異常）**が**正常**であることを確認します。
6. メールボックスを開きます。
7. 件名が**[FieldOps監視] 公開環境が復旧しました**のメールが届いていることを確認します。

## 必要な権限

このGAS監視が使う権限は次の5つだけです。

- 現在のスプレッドシートを読み書きする権限
- 外部URLへアクセスする権限
- メールを送信する権限
- 10分ごとのトリガーを作成、確認、削除する権限
- 実行ユーザーのメールアドレスを取得する権限

Googleパスワード、Renderトークン、Cookie、APIキーは使いません。

共有設定は非公開のまま運用してください。

## 困ったとき

1. メニューに**FieldOps監視**が出ない場合は、スプレッドシートを再読み込みします。
2. 権限承認で止まった場合は、Apps Script画面から**setupMonitoring**をもう一度実行します。
3. 通知メールが届かない場合は、**監視設定**シートの**通知先メール**と迷惑メールフォルダを確認します。
4. **runHealthCheck**のトリガーが2件以上ある場合は、**監視を停止**を押してから**10:00〜18:00の10分監視を開始**を押します。
5. 公開URLを変更した場合は、**監視設定**シートの**公開URL**を`https://fieldops-portfolio.onrender.com`へ戻します。
6. 監視履歴が異常のままの場合は、公開デモをブラウザで開き、表示できるようになってから**テスト状態を戻す**を押します。
